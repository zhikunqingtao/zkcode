九 Crate 核心、组合根与 API 边界

Edition 2024 · Rust 1.97 · Tokio · workspace 依赖单向流动 · unsafe_code = forbid。

窄屏依赖摘要

  • zk-core → tools / mcp / authz / engine / server
  • zk-protocol → db / llm / authz / engine / server
  • zk-tools + zk-db + zk-llm → zk-engine → zk-server
  • zk-mcp + zk-authz → zk-server

04 · Conversation engine

对话引擎、上下文与恢复主循环

REST / SSE / WS / CLI 最终复用同一 ConversationService 与 Engine；用户消息先落库再访问外部 Provider。

多轮执行主链

Prepare RunSession / Workspace 校验
Persist用户消息 + Run + Workbench
Build Context历史 / 附件 / Prompt / Tools
Provider SSE文本 / 思考 / tool_use
AdmissionHook + 授权 + 动态复验
ToolExecutor并发执行 + 进度事件
Rehydrate按模型声明序回填结果
Terminateend_turn / cancel / error / ceiling

单 Session 同时只允许一个活跃 Run；第二个普通查询直接得到 busy，不在内部排队。运行中用户输入走 run_input。

Run 与取消树

  • 默认对话循环上限：1024 turns。
  • Session → Run → Tool Call 三层 CancellationToken。
  • 工具进度与完成按到达顺序推送，下一轮模型输入保持原调用声明顺序。
  • Run / Task / Swarm 遗留状态在进程启动时恢复或标记 interrupted。

System Prompt 组成

  • 固定身份、安全约束、工具规范、环境信息。
  • 项目根 zhikun.md 与 zhikun.local.md，5 秒级热重载。
  • Feature Flag 动态段、Scratchpad、Token Budget、工具目录。
  • 用户级 MEMORY.md 不会自动作为 project memory 注入。

上下文级联

  • Token 精确计数或模型比例估算。
  • 工具结果 Snip、Micro Compact、Incremental Collapse、完整摘要。
  • 图片 / Base64 预算守卫，必要时缩放和替换。
  • 保持 tool_use / tool_result 成对完整，压缩失败有确定性兜底。

错误与 413 恢复

  • 上下文超限时缩小消息集并重试当前轮。
  • 同 Provider 指数退避并尊重 Retry-After。
  • 跨 Provider 只在尚未输出内容且错误可安全重试时发生。
  • 终止原因与错误摘要写入 Run Envelope 和事件日志。

WebSocket 顺序与恢复

  • MessageSink 将 Engine 与 Server 解耦；HubSink 顺序等待发送。
  • 每连接 mpsc 容量 256；关键事件发送失败进入 Session pending。
  • 重连绑定后恢复消息、活动工具、运行态与持久交互。
  • 应用层 ping/pong 负责连接活性。

费用、观测与快照

  • Provider Usage 汇总到会话与全局 AtomicCostTracker。
  • 文件写前 SnapshotSink 记录原状态，支持 Rewind 与 Diff。
  • Run 事件、结构化观测和前端 Activity 分层记录。
  • Workbench 将请求、结果、验收标准与证据绑定。

五种权限模式

defaultplanaccept_edits dont_askauto_approve

模式只改变人工确认策略；路径安全、敏感数据、Hook、主体绑定和执行前复验始终生效。

授权主体与复用

  • 绑定 root Session / Run、current Run、workspaceKey 与 authorizationRoot。
  • Grant 可按 once / run / session / workspace 等受限范围匹配。
  • 高风险操作通常不能复用长期 Grant。
  • 最终复验与 tool_started 事件在同一写事务。

持久 Interaction

  • 请求、版本、deadline、delivery generation 与 operationHash 落库。
  • 用户决策通过 REST CAS，陈旧版本返回冲突。
  • 进程重启与 WS 重连后继续投递未决请求。
  • UI 展示确认不能替代用户授权决策。

06 · Agent, LLM, MCP & extensions

Agent 协作、模型路由与扩展生态

子 Agent 继承同一数据库、授权、Hook、费用、快照、摘要与取消树；外部能力统一适配为 Tool。

Agent / Task

  • 子 Agent 创建独立 child Session 与 Run，并保留 parentRun 关联。
  • 前台 / 后台执行、Mailbox 双向消息、Checkpoint 与 Task 状态。
  • 全局并发 30、单 Session 10、嵌套深度 3。
  • 子 Agent 默认 50 turns；结果上限 100,000 字符。
  • 默认超时 5 分钟、最大 30 分钟、优雅停止 30 秒。

Coordinator / Team / Swarm

  • 唯一生产 Coordinator 持 Team、Swarm 运行态、取消表与事件总线。
  • Workflow Phase、Worker 状态与 Teammate 消息通过 WS 投影。
  • Swarm durable projection 复用 Activity，调度运行态留在进程内。
  • Agent/Task/Swarm 共用真实子代理执行器。

路由、重试与熔断

  • 模型优先按所有者路由；未知模型回落默认 Provider，再回落首个可用 Provider。
  • Fallback Chain 最多形成 3 个候选模型。
  • 同 Provider 标准重试最多 10 次调用，再按安全条件跨 Provider。
  • 连续 3 次 5xx 后熔断约 30 秒；全部 degraded 时 fail-open。
  • SQLite 保存的密钥更新后热替换 Registry。

MCP Client

  • 配置优先级：环境 → ~/.zk/mcp.json → workspace .zk/mcp.json。
  • STDIO、SSE、Streamable HTTP、WebSocket 四类传输。
  • 发现 tools / resources / prompts 并动态适配到 ToolRegistry。
  • 首次连接最多 4 次尝试；掉线后指数退避、抖动、最多 5 次、并发重连 2。
  • 30 秒健康检查，连续 2 次 ping 失败进入异常处理。

Reverse MCP Server

initialize · ping · tools/list · tools/call · resources/list · resources/read

复用本地 ToolRegistry、Hook、Admission 和审计；对外暴露的是受控能力，不是绕过网关的直通层。

Skill 与 Plugin

  • Skill：内建与磁盘多级来源、参数替换、约 500 ms 文件观察和热重载。
  • Skill 执行仍只获得当前可用工具的交集。
  • Plugin：扫描 .zk/plugins/{name}/manifest.toml，支持 install/uninstall/reload。
  • Plugin 当前是本地 manifest 管理，不是原生代码动态装载或远程市场。

08 · Data, delivery & verification

持久化、证据与可验证交付闭环

SQLite 是核心事务业务库，但 Snapshot、Blob、配置、记忆、附件、Hook、Replay 与观测仍使用受控文件存储。

SQLite 运行模型

  • 默认 .zk/data.db，bundled SQLite + Refinery。
  • 单 Writer Mutex 串行写；Reader 数按 CPU 核数轮转。
  • 同步访问经 spawn_blocking；WAL、foreign keys、5 秒 busy timeout。
  • 目录通常 0700；DB/WAL/SHM 通常 0600。
  • 25 张业务表；物理可见表另含 refinery_schema_history 与 sqlite_sequence，合计 27。

25 张业务表 · 会话/执行

sessions · messages · run_envelopes · run_event_log · tasks · agent_checkpoints · file_snapshots · activities · anomaly_events

25 张业务表 · 配置/授权

25 张业务表 · 交付/证据

run_workbench_bindings · run_acceptance_criteria · evidence_bundles · evidence_items · regression_scripts · artifact_manifests · artifact_entries

数据库一致性边界

  • Run、Interaction、Grant 与事件使用事务与 CAS 保持权威。
  • Web、REST、CLI 与工具共享同一 Db 句柄和 Repository。
  • Swarm durable projection 复用 activities，没有独立 Swarm 表。

进程内易失状态

Run 映射 · CancellationToken · WS Clients / pending · bounded queues · Agent scheduler · Dialog pending · REPL sessions · MCP/Python process handles。

重启后从数据库恢复可恢复投影，或将遗留活动状态标记为 interrupted。

09 · Observability, privacy & operations

观测、隐私、启动恢复与工程门禁

结构化日志、指标、Run 事件与工作区 JSONL 分层记录；开发生命周期由 ./dev 统一编排。

结构化观测

  • Rust tracing JSON，级别由 ZK_LOG / RUST_LOG 控制。
  • 进程内 bounded observability recorder + workspace JSONL sink。
  • Run Event Log 负责恢复事实，Activity 负责用户可见技术记录。
  • /metrics 暴露轻量 Prometheus 文本。

健康与诊断

  • /api/health、live、ready、auth status、doctor。
  • Python、MCP、Provider、数据库与工作区能力分开报告。
  • ./dev doctor --deep 验证工具链、端口、Socket 与 Headless Browser。

数据与隐私

  • .env、.zk/data.db、~/.zk 与日志均可能含密钥或项目数据。
  • 模型、联网工具、远程 MCP、语音和远程图片会形成外部传输。
  • 共享演示凭据不是私人秘密，不用于敏感内容。
  • 同一用户权限下的其他进程仍可能读取本地文件。
